## 三、发帖步骤（图文说明）

### 步骤 1：打开初赛专区

在浏览器中打开初赛专区地址：

```
https://forum.trae.cn/c/38-category/40-category/40
```

确认页面显示为"初赛专区"。

### 步骤 2：点击「发帖」

在页面右上角或专区页面中找到「发帖」按钮，点击进入发帖编辑器。

### 步骤 3：选择标签

在标签栏中选择：**学习工作**

> 注意：标签必须与报名赛道一致，否则可能影响评审。

### 步骤 4：填写标题

在标题栏中粘贴以下标题（完整复制，不可修改）：

```
【学习工作赛道】dev-memory — 项目级 AI 记忆系统，让开发记忆成为随项目走的轻量资产
```

### 步骤 5：粘贴正文

1. 打开 `初赛Demo帖正文_20260715-0930.md` 文件
2. 找到第一条 `---` 分隔线（即"标签：学习工作"上方的那条）之后的内容
3. 从"标签：学习工作"开始，复制到文件末尾的所有内容
4. 粘贴到社区发帖编辑器的正文区域
5. 检查格式是否正常（标题层级、列表、加粗等）

> 注意：社区编辑器可能对 Markdown 格式支持有限，粘贴后请检查：
> - 标题（##）是否正确显示
> - 列表（- 和数字）是否正确缩进
> - 加粗（**）是否正常显示
> - 代码块是否正确渲染

### 步骤 6：上传 Demo Zip 文件

1. 在编辑器中找到文件上传按钮（通常是回形针图标或"上传"按钮）
2. 选择准备好的 Demo Zip 文件
3. 等待上传完成（进度条到 100%）
4. 确认文件已成功附加到帖子

> 注意：社区限制文件大小 20MB 以内。如文件过大，请压缩或精简 Demo HTML 内容。

### 步骤 7：插入截图

1. 在正文中找到以下占位符位置：
   - `【截图1：占位 - 在TRAE中开发SKILL.md的过程截图】`
   - `【截图2：占位 - 寄生式注入TRAE记忆系统的过程截图】`
   - `【截图3：占位 - github-trending项目实战验证截图】`
2. 将占位符文字替换为对应的截图图片
3. 在编辑器中使用图片插入功能上传截图
4. 确认截图在正文中正确显示

### 步骤 8：填入 Session ID 和报名帖链接

在正文中找到以下占位符，替换为实际内容：

- `【Session ID 1：占位 - 双击TRAE对话头像复制】` → 替换为实际 Session ID 1
- `【Session ID 2：占位 - 双击TRAE对话头像复制】` → 替换为实际 Session ID 2
- `【Session ID 3：占位 - 双击TRAE对话头像复制】` → 替换为实际 Session ID 3
- `【报名帖链接：占位 - 填入已通过的报名帖链接】` → 替换为报名帖 URL

> 注意：Session ID 是评审验证开发过程真实性的关键凭证，务必填写真实有效的 ID。

### 步骤 9：发布

1. 最终检查全文内容，确认无遗漏
2. 确认所有占位符已替换为实际内容
3. 确认 Demo Zip 文件已上传
4. 确认截图已正确显示
5. 确认 Session ID 和报名帖链接已填入
6. 点击「发布」按钮
7. 发布后立即查看帖子，确认显示正常

## 五、Session ID 获取方法

Session ID 是评审验证开发过程真实性的关键凭证，每个对话都有唯一的 Session ID。

### 获取步骤

1. **打开 TRAE**：启动 TRAE IDE
2. **找到开发 dev-memory 时的对话**：在对话历史列表中，找到开发 dev-memory 相关的对话
   - 建议查找以下关键对话：
     - 开发 SKILL.md 技能文件的对话
     - 寄生式注入 TRAE 记忆系统的对话
     - github-trending 项目实战验证的对话
3. **双击对话头像**：在对话列表中，双击该对话的头像
4. **复制 Session ID**：双击后 Session ID 会自动复制到剪贴板
5. **记录 Session ID**：将复制的 Session ID 记录下来

### 需要 3 个不同的 Session ID

| 编号 | 对应步骤 | 对话内容 |
|------|---------|---------|
| Session ID 1 | Step 1 | 在 TRAE 中开发 SKILL.md 的对话 |
| Session ID 2 | Step 2 | 寄生式注入 TRAE 记忆系统的对话 |
| Session ID 3 | Step 4 | github-trending 项目实战验证的对话 |

> 注意：3 个 Session ID 必须来自 3 个不同的对话，不能重复。

## 六、Zip 打包方法

### 方法一：Windows 右键压缩（推荐）

1. 打开文件所在目录：`D:\trae\traeworkspace\dev-memory\competition\`
2. 找到 `Demo_dev-memory_20260710-1734.html` 文件
3. 右键点击该文件
4. 选择「发送到」→「压缩(zipped)文件夹」
5. Windows 会自动生成同名的 Zip 文件：`Demo_dev-memory_20260710-1734.zip`
6. 检查 Zip 文件大小是否小于 20MB

### 方法二：使用 7-Zip

1. 右键点击 Demo HTML 文件
2. 选择「7-Zip」→「添加到压缩包」
3. 压缩格式选择「zip」
4. 点击「确定」

### 验证 Zip 文件

1. 双击打开 Zip 文件，确认包含完整的 Demo HTML
2. 将 Zip 文件解压到临时目录，打开 HTML 文件确认能正常运行
3. 检查文件大小：右键 → 属性 → 确认小于 20MB

> 注意：如果 Demo HTML 依赖外部资源（如 JS、CSS、字体文件），请确保所有依赖文件都包含在 Zip 中。建议将 Demo HTML 及其依赖文件放在同一文件夹内，然后压缩整个文件夹。
